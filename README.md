# Research Paper Classifier

A machine learning project that classifies research paper abstracts into three categories:

- Science
- Business
- Social Science

## Project Goals

- Collect and prepare research paper abstracts.
- Preprocess text using NLP techniques.
- Extract features using Bag of Words and TF-IDF.
- Train and compare six machine learning classifiers.
- Evaluate models using accuracy, precision, recall, F1-score, and confusion matrices.
- Build a demo to classify new research abstracts.

## Tech Stack

Python, Pandas, Scikit-learn, NLTK, Matplotlib, Seaborn, Jupyter Notebook
